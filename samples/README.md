# Sample images

This folder is for **synthetic** face images (AI-generated people who do not exist) and one group
image, so reviewers can try the app without using photos of real people.

It is currently empty on purpose: no synthetic images were added yet. Never add photos of real
people here.

## How to fill it

1. Generate 3-5 single-face portraits with a generator that allows redistribution, for example a
   StyleGAN-based generator you run yourself, or images explicitly released under CC0.
2. Create one group image by compositing several of those synthetic faces.
3. Save them as `face_1.jpg` ... `face_5.jpg` and `group.jpg` (JPEG, under 10 MB each).
4. Record every image in the table below with its source and licence.

| File | Source (tool or URL) | Licence |
|------|----------------------|---------|
| _none yet_ | | |

## Trying the app with them

1. Log in as an officer and register a case using `face_1.jpg`.
2. Open `/report_sighting` and upload `group.jpg` (it should contain a face from `face_1.jpg`).
   The case is flagged as a match that needs human review.
3. Upload a photo of a face you did not enrol to check that no match is raised.
